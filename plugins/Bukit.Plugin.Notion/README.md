# Bukit.Plugin.Notion

`Bukit.Plugin.Notion` is a process plugin for consuming Notion handoff artifacts generated by `Bukit.Plugin.Import`.

Current phase: `PR-Notion-001 skeleton`.

Implemented protocol surface:

- `handshake`
- `manifest`
- `invoke` with unsupported-command diagnostics

The plugin is intentionally separate from Import. Import remains a local handoff producer, while this plugin owns future Notion network access and the `NOTION_TOKEN` environment permission.
