# Bukit.Plugin.Notion

`Bukit.Plugin.Notion` is a process plugin for consuming Notion handoff artifacts generated by `Bukit.Plugin.Import`.

The plugin is intentionally separate from Import. Import remains a local handoff producer with no network or token permission, while this plugin owns Notion network access and the `NOTION_TOKEN` environment permission.

## Commands

```bash
bukit notion validate-seed ./notion-seed
bukit notion validate-database-map ./notion-seed/notion-database-map.yaml

bukit notion push \
  --seed ./notion-seed \
  --database-map ./notion-seed/notion-database-map.yaml \
  --mode create \
  --dry-run

bukit notion push \
  --seed ./notion-seed \
  --database-map ./notion-seed/notion-database-map.yaml \
  --mode upsert \
  --token-env NOTION_TOKEN

bukit notion push \
  --seed ./notion-seed \
  --database-map ./notion-seed/notion-database-map.yaml \
  --mode replace \
  --confirm-replace \
  --token-env NOTION_TOKEN
```

## Push Modes

- `create`: creates one Notion page per seed record.
- `upsert`: queries by `uniqueField`; updates properties when one page matches, otherwise creates.
- `replace`: requires `--confirm-replace`; queries by `uniqueField`, updates properties, deletes existing children, and appends replacement paragraph blocks from seed content.
- `--dry-run`: validates seed/map and writes planned reports without reading token or calling Notion.

## Reports

Successful push and dry-run commands write:

- `.bukit/reports/plugin-output/notion/notion-push-report.json`
- `.bukit/reports/plugin-output/notion/notion-push-report.md`

Reports must not contain the Notion token or raw secret values.

## Packaging

Build a self-contained package:

```bash
scripts/build/notion-plugin-package.sh TestResults/notion-plugin-package Release
```

Run the local smoke test without real Notion API access:

```bash
scripts/smoke/notion-plugin-package.sh TestResults/notion-plugin-package Release
```
