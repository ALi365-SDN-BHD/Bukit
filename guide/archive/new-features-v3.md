# Historical Feature Notes

This archive page exists only for retired or superseded feature notes. Current
Core behavior is documented from source in the active guide:

- User-facing behavior: `guide/user`.
- Maintainer contracts: `guide/dev`.
- Agent workflows: `guide/skills`.

Do not treat archived feature notes as an implementation contract. Before moving
any historical note here, verify that the corresponding current behavior is
covered by source-driven documentation and a lightweight check under `scripts/`.
