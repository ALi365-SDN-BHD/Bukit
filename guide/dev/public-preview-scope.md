# Public Preview Scope

Core docs describe stable behavior. Labs and preview areas may describe future
or optional workflows, but they cannot be used as proof of current Core support.

## Stable In Core

- Static command registry.
- Strict config.
- Markdown and Notion content sources.
- Local themes.
- Scriban rendering.
- Routing, list routes, taxonomy, and pagination.
- SEO, GEO, publish audit, search, feeds, sitemap, and build reports.
- GitHub Pages deployment.

## Outside Stable Core

- Clone workflows.
- HTML demo import workflows.
- Intent-driven site generation.
- Webhook services.
- Remote theme registries or marketplaces.
- General external plugin ecosystem claims.
