# Bukit Routing

Route priority is route override, collection rule, then `site.permalinks`.
Output paths are derived from URLs; `outputPath` fields are rejected.

List route graph generation covers collection lists, filtered lists, taxonomy
routes, and pagination. Verify changes with `bukit build` and route reports.
