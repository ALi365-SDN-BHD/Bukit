# Bukit Core Agent Skills

Kemahiran ini mengajar pembantu AI membina dan menyelenggara laman web dengan Bukit
Core yang stabil. Ia hanya menerangkan tingkah laku Core semasa; sumber benar ialah
kod dalam `src/Bukit-Core` (`BukitCliSpecs.cs` untuk arahan, `AppConfig.cs` dan
pengesah konfigurasi untuk `site.yaml`).

Mulakan dengan [`using-bukit`](using-bukit/SKILL.md), kemudian muatkan kemahiran
khusus untuk tugas itu. Senarai penuh ada dalam [README.md](README.md).

Jangan anggap Labs, clone, import, intent, webhook, tema jauh, pasaran plugin, atau
plugin luaran sebagai Core kecuali pengguna meminta workflow Labs secara jelas
([`guide/labs-skills`](../labs-skills/README.md)).
