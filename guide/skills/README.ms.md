# Kemahiran Agent Bukit Core 1.0

Direktori ini menggantikan pek lama untuk Core 1.0. Pek lalai hanya memuatkan kebolehan Core yang stabil; keupayaan clone, import, webhook, registry tema, wizard tema, dan template tools dipisahkan ke `guide/labs-skills/`.

## Sempadan Core

Arahan Core lalai:

`build`, `doctor`, `config`, `preview`, `dev`, `clean`, `version`, `completion`, `seo`, `geo`, `publish`, `deploy`.

Jangan muatkan `guide/labs-skills/*` melainkan pengguna meminta Labs atau ciri eksperimen secara jelas.
