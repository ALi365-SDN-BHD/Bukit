# Bukit Core Agent Skills

Direktori ini hanya menerangkan tingkah laku Core yang stabil. Sumber benar
ialah registry CLI, model konfigurasi, pipeline binaan, dan ujian semasa.

Jangan anggap Labs, clone, import, intent, webhook, tema jauh, atau pasaran
plugin sebagai Core kecuali pengguna meminta workflow Labs secara jelas.
