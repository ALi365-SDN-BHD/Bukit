## Configuration Guide

Bukit uses `site.yaml` for configuration. Here are the key sections:

### Site Settings

```yaml
site:
  name: my-site
  title: My Site
  url: https://example.com
  baseUrl: /
```

### Content Sources

Bukit supports Markdown and Notion as content sources.

### Theme Configuration

You can use built-in themes, custom layouts, or remote themes.
