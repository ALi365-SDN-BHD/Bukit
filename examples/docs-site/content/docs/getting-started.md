## Getting Started with Bukit

### Prerequisites

- .NET 8.0 or later
- A text editor

### Installation

```bash
dotnet tool install -g bukit
```

### Create a New Site

```bash
bukit new my-site
cd my-site
bukit build
```

For more details, see the [Configuration](/docs/configuration/) guide.
