# Bukit Core 1.0 Skills

Start with `using-bukit/SKILL.md` when the user asks for Bukit work. The Core pack is limited to the stable CLI registry in `src/Bukit-Core/Bukit.Cli/Cli/BukitCliSpecs.cs`.

Load order: gateway -> CLI reference when commands are involved -> config -> focused domain skill.

Labs skills under `guide/labs-skills/` are explicit opt-in only.
