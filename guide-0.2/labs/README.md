# Bukit Labs Boundary

Labs documents are opt-in drafts for workflows that are not part of Bukit Core
1.0. They may preserve old design intent or describe future implementation
paths, but they must not be linked as the default Core developer path.

## Labs Drafts

| Topic | File |
|---|---|
| Remote theme source | [theme-source.md](./theme-source.md) |
| Scaffolding init/create | [init-create.md](./init-create.md) |
| Intent CLI | [intent-cli.md](./intent-cli.md) |
| Webhook trigger | [webhook.md](./webhook.md) |
| External plugin protocol | [external-plugin-protocol.md](./external-plugin-protocol.md) |

## Rule

Every Labs workflow must state which Core boundary blocks it today and which
source/test surfaces must change before it can move into Core documentation.
