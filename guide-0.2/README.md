# Bukit Guide

This guide tree is aligned with Bukit Core 1.0.

- [User Guide](user/README.md) covers stable user workflows.
- [Developer Guide](dev/README.md) covers Core maintainer contracts.
- [Agent Skills](skills/README.md) contains Core-aligned agent instructions.
- [Labs](labs/README.md) contains explicit non-Core or experimental notes.
- [Archive](archive/README.md) contains historical material that must not be used as a current contract.

Core docs use the current code contracts as source of truth: `BukitCliSpecs.cs`, `ConfigStrictFieldValidator.cs`, `ConfigJsonSchemaGenerator.cs`, `ThemeManifestLoader.cs`, `PluginRegistry.cs`, and `CoreBoundaryTests.cs`.
