# Bukit Labs Skills

Labs skills are explicit opt-in only. The Core gateway must not load them by default.

These areas are not part of the Bukit Core 1.0 command surface:

- website clone workflows
- local HTML demo import workflows
- webhook-triggered build servers
- theme registry and discovery
- theme wizard or preset generation
- theme package/install flows
- template command tooling
- component-system experiments beyond the Core `theme.yaml` reader

Use a Labs skill only when the user explicitly asks for Labs, experimental, or a named workflow in this directory.
